# Leaf Nest 术语表

## 正文图片

EPUB 当前章节内容中成功加载的 `img` 元素。书架封面、书籍信息弹窗封面及应用界面图标不属于正文图片。

## 图片预览

用户点击正文图片后，在阅读器上方的模态层中查看该图片的状态。图片预览不改变章节内容、分页和阅读进度。

## 图片变换

预览状态下对图片执行的缩放、平移或复位操作。图片变换只影响当前预览会话，关闭预览后不会保存。

## 图片源

预览使用的图片地址。它可能是从 EPUB 压缩包资源生成的 Blob URL，也可能是章节中能够成功加载的其他地址。

## 阅读器

承载阅读界面与工具栏的父级 React 页面。正文内容显示在阅读器内的同源 iframe 中。

## 阅读会话

用户一次进入阅读器到离开阅读器的生命周期。阅读会话本身不等于有效阅读时间，其中可以包含有效阅读区间和因页面不可见、窗口失焦或用户空闲而产生的暂停区间。

## 有效阅读区间

阅读器页面可见、窗口位于前台且用户未处于空闲状态的一段连续时间。连续 60 秒没有翻页、滚动、点击或键盘操作后，当前区间结束；用户再次交互时开始新的区间。有效阅读区间是阅读统计的持久化事实，关联用户、书籍、阅读会话、统计日期、设备时区和有效秒数。

## 有效阅读时间

一个或多个有效阅读区间的持续时间之和。仅打开阅读器但在后台、锁屏或空闲的时间不属于有效阅读时间。

## 每日阅读汇总

按阅读发生时的设备时区，归属于同一统计日期的有效阅读时间总和。它由有效阅读区间聚合得出，是首页阅读热力图的主要数据来源，而不是独立的事实来源。

## 统计日期

一段有效阅读时间按阅读发生时的设备时区对应的本地日历日期。跨越本地午夜的区间拆分到两个统计日期；已经归档的数据不会因用户旅行、修改设备时区或在其他时区查看首页而重新归属。

## 已删除书籍阅读记录

原书籍已从书架删除但继续保留的有效阅读区间。它仍参与每日阅读汇总，但不再关联书籍实体，并在需要显示来源时统一标记为“已删除书籍”。删除账号时，这类记录与其他账号数据一并删除。

## 重叠阅读区间

同一账号由多个标签页或设备产生、UTC 时间范围部分或全部重合的有效阅读区间。原始区间分别保留，但聚合时对时间范围求并集，重叠部分只计入一次。若区间对应不同统计日期，重叠部分归入较早开始的区间；开始时间相同时按区间 ID 稳定排序。

## 阅读检查点

客户端对尚未结束的有效阅读区间定期保存并上报的累计状态。检查点默认每 30 秒产生一次，并在暂停或离开阅读器时立即产生；同一区间的重复检查点通过稳定区间 ID 幂等更新，不会重复累加时长。

## 阅读热力图

首页“阅读活动”卡片中按统计日期展示每日阅读汇总的 53 周网格。每列为一周，按周一至周日纵向排列；没有真实记录的未来日期留空，不表示零阅读。跨越国际日期变更线后，已归档到相对当前设备而言的未来日期的数据仍正常显示。颜色采用固定的四档非零时长阈值，使相同颜色在不同时间窗口内保持相同含义。组件使用方向键在日期间导航，并以文字同时表达日期、时长和等级。

## 计时启用时间

一个账号首次启用新版阅读计时器的时间。其设备时区对应的统计日期是该账号可信阅读时长历史的起点。

## 未统计日期

早于账号计时启用日期、因而没有可信阅读时长数据的日期。未统计不等于阅读 0 分钟，并在热力图中使用区别于零级色阶和未来空白日期的中性状态。

## 今日阅读时间

按当前设备统计日期聚合的有效阅读时间。它显示在首页“阅读活动”卡片的主摘要中。

## 正文可阅读状态

当前章节已写入 iframe、完成必要布局，并已恢复用户阅读位置的状态。只有处于该状态时，阅读器才允许开始有效阅读区间；下载、解压、解析和位置恢复过程不属于正文可阅读状态。

## 阅读器内辅助操作

用户在正文可阅读时进行的目录浏览、全文搜索、图片预览、划线、分享、字体设置或书籍信息查看等操作。这些操作属于当前阅读会话并可重置空闲计时，但不会取消 60 秒无操作后暂停的规则。

## 阅读历史保留期

有效阅读区间从产生起保留至账号删除。移出首页热力图的 53 周窗口或删除相关书籍都不会缩短该保留期。

## 单栏模式

章节内容纵向连续滚动的阅读模式。

## 双栏模式

章节内容按列分页并横向翻页的阅读模式。
