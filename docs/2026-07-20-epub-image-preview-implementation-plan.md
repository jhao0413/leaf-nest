# EPUB 正文图片预览实施计划

## 目标

让用户在单栏和双栏阅读模式中点击任意成功加载的正文图片，在覆盖整个阅读器的模态框中放大查看，并在桌面端和移动端获得一致的缩放、平移与关闭体验。

## 领域模型

```text
章节 iframe
  └─ 正文图片（成功加载）
       └─ 触发预览请求（图片源 + 触发元素）
            └─ 图片预览会话
                 ├─ 图片变换（缩放 + 平移）
                 ├─ 模态框生命周期
                 └─ 阅读器快捷键暂停
```

核心状态只有“当前预览图片”。没有当前图片时预览关闭；存在当前图片时预览打开。缩放和平移属于预览组件内部的临时状态，关闭或切换图片后复位，不进入全局 store，也不持久化。

## 实现步骤

### 1. 添加缩放组件依赖

安装 `react-zoom-pan-pinch`，将其锁定到项目 lockfile。HeroUI `Modal` 继续负责遮罩、焦点约束和关闭语义。

### 2. 建立 iframe 图片交互桥接

在 `iframeHandler.ts` 中增加可复用的图片预览绑定函数：

- 在 iframe 文档根节点使用事件委托处理 `click` 与 `keydown`，避免逐张图片维护监听器。
- 仅当事件目标为已成功加载的 `img` 时触发；判断条件为 `complete && naturalWidth > 0`。
- 为可预览图片补充指针样式、可聚焦能力和按钮语义。
- `Enter` 与空格触发预览；空格必须阻止默认滚动和向父窗口转发。
- 图片位于链接中时阻止链接导航。
- 返回清理函数，章节重载、模式切换或组件卸载时移除监听和增强属性。

桥接回调向父级传递图片 `currentSrc || src` 以及触发元素引用。图片说明不进入预览 UI。

### 3. 新增统一图片预览组件

创建 `ImagePreviewModal`：

- 使用 HeroUI `Modal` 构建全屏深色遮罩。
- 使用 `TransformWrapper` 和 `TransformComponent` 承载图片。
- 初始完整适应视口，缩放范围 `0.5×–4×`。
- 开启滚轮、双击、拖动与双指缩放。
- 提供带可访问名称的放大、缩小、顺时针旋转、复位和关闭按钮。
- 仅遮罩自身点击关闭，拖动和点击图片不关闭。
- 每次打开时通过组件 key 或显式复位创建新的图片变换会话。
- 关闭后把焦点恢复到 iframe 中的触发图片。

虽然不显示图片说明，预览图仍使用原图 `alt` 作为替代文本；无 `alt` 时使用本地化的通用替代文本。

### 4. 接入两种阅读模式

在 `SingleColumnRenderer.tsx` 与 `DoubleColumnRenderer.tsx` 中：

- 保存当前预览图片状态。
- iframe 准备完成后建立图片交互桥接。
- 渲染同一个 `ImagePreviewModal`。
- 关闭预览时清空状态并恢复焦点。
- 将 `isImagePreviewOpen` 传入翻页快捷键逻辑，在预览期间禁用方向键和空格翻页。

### 5. 调整快捷键接口

为 `useKeyboardShortcuts` 增加 `enabled`（默认 `true`）或等价开关。预览打开时不响应翻页与搜索快捷键，由模态框独占键盘交互；关闭后自动恢复。

### 6. 国际化

在中英文消息中增加图片预览、放大、缩小、复位与关闭的可访问标签。界面不展示标题或图片说明。

## 验收标准

- 单栏和双栏模式中，任意成功加载的正文 `img` 点击后均打开预览。
- 内嵌图片、SVG、GIF 和成功加载的外链图片使用相同行为。
- 图片被链接包裹时只打开预览，不跳转。
- 失败图片不会打开预览，也不出现额外错误提示。
- 桌面端支持滚轮/双击缩放和拖动，移动端支持双指缩放和单指拖动。
- 缩放限制为 `0.5×–4×`，放大、缩小、旋转、复位按钮有效。
- 关闭按钮、`Escape` 和直接点击遮罩均可退出；拖动图片不会误退出。
- 图片可通过 `Tab` 聚焦，并通过 `Enter` 或空格打开；关闭后焦点返回原图片。
- 预览期间方向键和空格不会触发翻页，关闭后翻页快捷键恢复。
- 打开与关闭预览不改变当前章节、页码、滚动位置、分页计算或阅读进度。
- 章节切换和阅读模式切换后没有重复监听，也不会预览上一章节的图片。

## 测试计划

- 为 iframe 图片桥接添加单元测试：成功/失败图片、键盘触发、链接阻止、清理与重复绑定。
- 为 `ImagePreviewModal` 添加组件测试：开关、控制按钮、关闭方式、替代文本和焦点恢复。
- 扩展两种阅读器流程测试：预览状态与快捷键隔离、章节切换后的监听生命周期。
- 执行类型检查、Web 测试与 lint。

## 风险与缓解

- Blob URL 在章节切换后失效：预览随章节生命周期关闭，不跨章节保存图片源。
- iframe 键盘事件会转发到父窗口：图片激活键在 iframe 内提前消费，父级快捷键同时由预览状态禁用。
- 双栏分页可能受样式变化影响：只设置光标和焦点轮廓，不修改图片尺寸与文档流。
- 手势拖动可能误触遮罩关闭：遮罩关闭必须检查事件目标为遮罩本身。
