# ADR 0001：EPUB 正文图片放大浏览

- 状态：已接受
- 日期：2026-07-20

## 背景

Leaf Nest 将 EPUB 章节内容写入同源 iframe，并提供单栏和双栏两种阅读模式。当前正文图片只能按章节排版尺寸查看，用户无法单独放大细节。

## 已确认决策

- 所有成功加载的正文图片都可点击预览，包括 EPUB 内嵌图片、SVG、GIF 和可加载的外链图片。
- 点击图片后，在覆盖阅读器的模态层中显示图片。
- 单栏、双栏以及桌面端、移动端使用一致的交互语义。
- 图片位于链接中时，点击优先打开图片预览，不触发链接跳转。
- 用户可通过关闭按钮、点击背景或按 `Escape` 退出预览。
- 使用项目已有的 HeroUI `Modal` 承载全屏预览，并引入 `react-zoom-pan-pinch` 处理图片缩放和平移。
- 预览中不显示 `figcaption`、`alt` 或 `title` 等图片说明。
- 加载失败的图片保持章节原样，不响应预览点击，也不额外提示错误。
- 图片打开时完整适应视口，缩放范围为 `0.5×–4×`，每次打开图片时重置变换状态。
- 桌面端支持滚轮缩放、双击缩放和拖动；移动端支持双指缩放和单指拖动。
- 预览提供放大、缩小、顺时针旋转和复位按钮；点击图片以外的背景关闭，拖动图片不会误触关闭。
- 正文图片可获得键盘焦点，并可通过 `Enter` 或空格打开；关闭预览后焦点返回触发图片。
- 预览打开期间暂停阅读器翻页快捷键，关闭后恢复。
- 所有成功加载的正文图片均可预览，不按尺寸或用途排除装饰性图片。

## 不在本次范围

- 下载图片。
- 在多张图片之间切换或显示缩略图。

## 候选实现

在 iframe 文档上使用事件委托捕获图片点击，将图片地址传递给父级 React 阅读器。父级使用 HeroUI `Modal` 和 `react-zoom-pan-pinch` 统一渲染图片预览。该方式可以让遮罩覆盖完整阅读器，并让两种阅读模式复用同一套预览组件。

## 影响

- 章节切换或重写 iframe 时，需要重新建立或正确清理事件监听。
- 打开预览时必须阻止图片外层链接的默认跳转。
- 预览不得改变 iframe 的分页尺寸、阅读位置或阅读进度。
- 模态框需要焦点管理、键盘关闭和可访问名称。
- 父级阅读器的方向键与空格翻页监听需要在预览期间禁用。
- `react-zoom-pan-pinch` 成为新的前端运行时依赖。
